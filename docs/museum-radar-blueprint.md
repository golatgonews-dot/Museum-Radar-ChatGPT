# Museum Radar Blueprint

Canonical blueprint: Google Doc stored in the Museum Radar project folder.

This repository copy will be used as the portable source-document version for the app build.

## Core principle

**Simple surface, deep capability.**

## v1 scope

- Upcoming exhibitions
- Calendar
- Map
- Expandable exhibition cards
- Basic filters
- New / updated indicators
- Interested / Planning / Attended states
- Priority Watchlist overrides

## Data source

The working source of truth is the Museum Radar Google Sheet. The app will begin with local JSON and later connect to the live structured data source.
